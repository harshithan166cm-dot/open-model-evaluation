# Open Model Evaluation

## 1. Project Overview

This project compares four open-weight AI models across different tasks to understand their accuracy, reasoning ability, coding performance, instruction following, and multilingual capabilities.

The project was developed as an individual hackathon submission under **Theme 1: Open Model Evaluation**.

## 2. Models Evaluated

| Model | Platform |
|---|---|
| GPT-OSS 20B | Groq |
| GPT-OSS 120B | Groq |
| Qwen 3.8 27B | Groq |
| Gemma 4 26B A4B IT | Google AI Studio |

## 3. Evaluation Categories

The evaluation includes 25 prompts across five categories:

1. Reasoning
2. Factual Knowledge
3. Instruction Following
4. Coding
5. Indian Languages

## 4. Evaluation Methodology

- The same prompts were prepared for all four models.
- A common system prompt and evaluation rubric were used.
- Responses were assessed on a scale of 0–4.
- Maximum possible score: 100 per model.
- This was a single-rater evaluation.

**Important:** P01–P15 contain observed model responses. P16–P25 contain simulated sample responses and scores, not actual model outputs. Therefore, combined scores are illustrative and should not be treated as verified experimental results.

## 5. Project Files

- `model_information.csv` – Model details.
- `evaluation_questions.csv` – Evaluation prompts and expected answers.
- `response_scorecard.csv` – Model responses and scores.
- `results_analysis.csv` – Comparative score analysis.
- `bonus_experiments.csv` – Additional experiment plans and observations.
- `screenshots/` – Project screenshots and evidence.

## 6. Tools and Platforms

- Groq Playground
- Google AI Studio
- Google Sheets
- GitHub

## 7. Limitations

- Only four models were included.
- The evaluation used a single human rater.
- Some responses were simulated rather than generated by the models.
- Multilingual responses were not independently verified by native speakers.
- Additional experiments require further execution.

## 8. Conclusion

This project provides a structured comparison of open-weight AI models across multiple evaluation categories. It also highlights the importance of consistent testing, transparent scoring, and documenting experimental limitations.
